# WSL 내부에서 Ollama, OpenCode, Java, React 개발 환경

## 1단계: WSL 시스템 업데이트 및 기본 도구 설치
가장 먼저 WSL 리눅스 패키지 시스템을 최신 상태로 만들고, 빌드에 필요한 기본 도구들을 설치합니다.

```bash
# 1. 패키지 리스트 업데이트 및 업그레이드
sudo apt update && sudo apt upgrade -y

# 2. curl, git, 빌드 필수 도구 설치
sudo apt install -y curl git build-essential

# 3. 고성능 무손실 데이터 압축 알고리즘 모듈
sudo apt-get install zstd
```

## 2단계: Java (JDK 17 또는 21) & Node.js (React용) 설치
Spring Boot와 React 개발을 위해 WSL 내부에 개발 런타임을 설치합니다. (버전은 프로젝트에 맞게 조절 가능합니다.)

```bash
# 1. SDKMAN을 이용한 Java 설치 (Java 관리용 가장 편한 도구)
curl -s "https://get.sdkman.io" | bash
source "$HOME/.sdkman/bin/sdkman-init.sh"

# 2. Java 17 설치 (Spring Boot 3.x 표준) - 필요시 21로 변경 가능
sdk install java 17.0.10-tem

# 3. Node.js 설치를 위해 NVM(Node Version Manager) 설치
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.7/install.sh | bash
source ~/.bashrc

# 4. LTS 버전 Node.js 및 React 생태계 필수 패키지 관리자 설치
nvm install --lts
npm install -g yarn pnpm

```

## 3단계: WSL용 Ollama 설치 및 Qwen 코딩 모델 다운로드
Windows에 Ollama를 설치하면 WSL과 연동할 때 포트 설정이 번거로울 수 있으므로, WSL 리눅스 내부에 Ollama를 직접 설치하는 것이 가장 깔끔하고 빠릅니다.

```bash
# 1. WSL 전용 Ollama 한 줄 설치 스크립트 실행
curl -fsSL https://ollama.com/install.sh | sh

# 2. (설치 완료 후) 내 PC 사양에 최적화된 Qwen 2.5 Coder 7B 모델 다운로드
ollama run qwen2.5-coder:7b
```
Tip: 모델 다운로드가 끝나면 터미널 프롬프트가 >>> 형태로 바뀝니다. 잘 작동하는지 확인 후 /exit를 입력해 빠져나오세요.


## 4단계: OpenCode CLI 설치 및 Ollama 연동
이제 AI 에이전트 역할을 할 OpenCode를 설치하고 로컬 Ollama와 연결합니다.

```bash
# 1. OpenCode CLI 글로벌 설치
npm install -g opencode-ai

# 2. OpenCode 환경 설정 시작 (대화형 가이드)
opencode configure

```
opencode configure 입력 후 가이드:

1. AI Provider를 물어보면 **Ollama**를 선택합니다.
2. Model 이름을 물어보면 방금 다운로드한 **qwen2.5-coder:7b**를 입력하거나 선택합니다.
3. Endpoint 주소는 기본값인 http://localhost:11434 그대로 엔터를 누릅니다.


## 5단계: VS Code 연동 및 프로젝트 시작
이제 Windows에 있는 VS Code를 WSL 환경과 연결해 주어야 합니다.

Windows에서 VS Code를 켭니다.

1. 왼쪽 확장(Extensions) 탭에서 WSL (Microsoft 제작)을 검색해 설치합니다.
2. 설치 후 F1 키를 누르고 WSL: Connect to WSL을 선택하여 WSL 환경의 창을 새로 엽니다.
3. VS Code 내장 터미널(`Ctrl + ``)을 열고, 본인의 Java/React 프로젝트 폴더로 이동한 뒤 아래 스크립트를 입력해 하네스(에이전트 구동 환경)를 초기화합니다.

```bash
# 프로젝트 폴더 내에서 실행
opencode init

# 이제 에이전트 실행!
opencode
```
