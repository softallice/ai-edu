# NotebookLM 교육자료 제작 가이드

ai-edu의 교육 문서(커리큘럼·문서 9종·하네스 가이드)를 **Google NotebookLM**에 올려
학습가이드 · 강의 슬라이드 · 퀴즈 · 플래시카드 · 오디오 개요(팟캐스트)를 자동 생성하는 파이프라인입니다.
[`notebooklm-py`](https://github.com/teng-lin/notebooklm-py)(비공식 CLI)를 사용합니다.

> ⚠️ 비공식 라이브러리입니다 — Google 내부 API를 사용하므로 예고 없이 동작이 바뀔 수 있고,
> 과도한 사용은 rate limit에 걸릴 수 있습니다. Google 계정 필요.

## 1. 준비

```bash
# 설치 (사내망 인증서 환경이면 --system-certs 필요)
uv tool install --system-certs "notebooklm-py[browser]"
export PATH="$HOME/.local/bin:$PATH"

# 인증 (최초 1회 — Chromium이 열리면 Google 로그인, 자동 감지 후 저장)
notebooklm login
notebooklm list      # 동작 확인
```

WSL에서는 WSLg가 브라우저 창을 띄웁니다. 첫 로그인 시 Chromium(~170MB)을 자동 다운로드합니다.
회사 SSO가 Edge 전용이면 `notebooklm login --browser msedge`.

## 2. 교육자료 생성

```bash
cd ~/work/ai-edu

# 1) 노트북 생성 + 교육 문서 11종 업로드 + 한국어 설정 (최초 1회)
./scripts/nblm-edu-materials.sh setup

# 2) 원하는 자료만 골라 생성 (각각 수 분 소요, audio는 ~20분)
./scripts/nblm-edu-materials.sh guide        # 수강생 학습 가이드 (Markdown)
./scripts/nblm-edu-materials.sh slides       # 강의 슬라이드 (PDF + 편집용 PPTX)
./scripts/nblm-edu-materials.sh quiz         # 차시 평가 퀴즈 (Markdown + 인터랙티브 HTML)
./scripts/nblm-edu-materials.sh flashcards   # 복습 플래시카드 (Markdown + HTML)
./scripts/nblm-edu-materials.sh audio        # 과정 소개 팟캐스트 (MP3, 한국어 대담)

# 전부 한 번에
./scripts/nblm-edu-materials.sh all
```

산출물은 `edu-materials/` 에 저장됩니다(gitignore — 생성물은 커밋하지 않음).

| 산출물 | 파일 | 교육 활용 |
|--------|------|----------|
| 학습 가이드 | `학습가이드.md` | 수강생 사전 배포 자료 |
| 강의 슬라이드 | `강의슬라이드.pdf` / `.pptx` | 강사 발표 자료 (PPTX는 수정 가능) |
| 퀴즈 | `퀴즈.md` / `.html` | 차시 마무리 평가 (HTML은 브라우저에서 바로 풀이) |
| 플래시카드 | `플래시카드.md` / `.html` | 용어·개념 복습 |
| 팟캐스트 | `과정소개-팟캐스트.mp3` | 과정 안내·사전 학습 (출퇴근 청취) |

## 3. 업로드되는 소스 (11종)

`setup`이 차시 라벨을 붙여 업로드합니다: README(개요) · docs/1~9(환경설정→커리큘럼) · harness-claude-code/README(실무 하네스).
문서를 갱신했다면 NotebookLM 웹 UI에서 해당 소스를 삭제 후 `setup` 재실행(또는 `notebooklm source refresh <id>`).

## 4. 커스터마이징

스크립트의 생성 프롬프트(따옴표 안 지시문)를 수정해 자료 성격을 바꿀 수 있습니다. 예:

```bash
# 차시별 슬라이드를 따로 만들고 싶을 때 (노트북 활성 상태에서 직접 실행)
notebooklm generate slide-deck --language ko --wait "3차시 PDCA 방법론만 다루는 슬라이드"
notebooklm download slide-deck edu-materials/3차시-PDCA.pdf --latest

# 난이도 높은 최종 평가
notebooklm generate quiz --difficulty hard --quantity more --wait "최종 수료 평가용"

# 비디오 개요 (실험적)
notebooklm generate video --format explainer --language ko --wait --timeout 1800 "과정 소개 영상"
notebooklm download video edu-materials/과정소개.mp4 --latest
```

전체 명령은 `notebooklm --help` 또는 [notebooklm-py CLI 레퍼런스](https://github.com/teng-lin/notebooklm-py/blob/main/docs/cli-reference.md).

## 5. 문제 해결

| 증상 | 해결 |
|------|------|
| `uv tool install` TLS 오류 | 사내망 인증서 — `--system-certs` 플래그 추가 |
| 로그인 시 `ERR_CERT_AUTHORITY_INVALID` | 사내망 TLS 가로채기 — 사내 루트 CA를 Chromium NSS 저장소에 등록: `certutil -A -d sql:$HOME/.pki/nssdb -t "C,," -n "Corp CA" -i /etc/ssl/certs/certificate.pem` (certutil은 `libnss3-tools` 패키지, sudo 불가 시 `apt-get download libnss3-tools && dpkg -x`로 추출 사용) |
| API 호출 시 인증서 오류 | `export SSL_CERT_FILE=/etc/ssl/certs/ca-certificates.crt` (파이프라인 스크립트에는 기본 적용됨) |
| `notebooklm: command not found` | `export PATH="$HOME/.local/bin:$PATH"` |
| 인증 오류 / 401 | `notebooklm login` 재실행 (세션 만료) |
| 로그인 브라우저가 안 뜸 (WSL) | WSLg 확인(`wsl --update`), 또는 Windows Chrome 로그인 후 `--browser-cookies` 방식은 WSL에선 불가 — WSLg 권장 |
| 생성이 멈춘 듯함 | 정상 — audio ~20분, slides ~5분. `notebooklm artifact list`로 상태 확인 |
| rate limit | 시간을 두고 재시도 (`--retry 3` 옵션) |
